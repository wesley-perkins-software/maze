Maze Start & End Icon Systems

Three complete color systems evaluated against your existing palette — traversal path (#3b82f6), hint/solution path (#22c55e), finish flag (#f59e0b).

Diagnosis: The start marker (slate gray + arrow) is visually weak — it reads as "placeholder" rather than "begin here." The finish flag is stronger but using flags for both start and end (as explored) creates confusion. The green hint path is too close in value to a potential green start marker.

System A — "Teal & Gold"

Start gets a confident teal with a play/arrow icon; finish becomes a gold star. No icon type is repeated. Hints shift to violet to free up green entirely.

Why teal for start?
Teal is cool and calm — "ready to begin." It's maximally distinct from amber (finish), blue (path), and violet (hints). No color collision.
Why star for finish?
A star communicates achievement and reward, not just "destination." It's universally understood and more satisfying than a pennant flag.
Why violet hints?
Frees green entirely. Violet reads as "magical guidance" — secondary, helper energy — rather than competing with the teal start marker.

System B — "Traffic Light"

Green = go, red = stop. The most universally legible wayfinding system on earth. Simple, zero ambiguity. Requires hints to change color.

Strength
Zero learning curve. Everyone understands green/red as go/stop. Maximum clarity, especially for first-time players.
Weakness
Red finish can feel punishing rather than rewarding. The hint path (amber) may feel like a "warning," not helpful guidance.
Accessibility
Red/green is the most common form of color blindness. Must rely on icon shape differentiation, not just color.

System C — "Map Pin"

Borrowed from digital maps: a teardrop pin for start (A), a destination pin for finish (B). Familiar from Google Maps / Apple Maps. Minimal icon vocabulary.

Strength
Teardrop pins are the most universally recognized "location" icon. Both markers use the same shape, so color alone differentiates them.
Weakness
Pin shape extends beyond the cell — takes more visual real estate, especially on dense mazes. Blue start blends with the blue traversal path.
Verdict
Familiar but generic. The pin metaphor is from navigation apps, not puzzle games. Loses the playful quality of the maze context.
Summary & Recommendation

Go with System A, with one tweak to consider

The teal + gold star system is the strongest choice: it keeps your existing amber/gold finish color, gives the start a distinct identity, and shifts hints to violet — a color that visually says "guidance" without competing. The icon shapes (play arrow vs. star) reinforce the semantic difference that color alone can't always provide.

Start marker

Teal circle (#0d9488) with a solid right-pointing play arrow ▶ in white. "Begin here, move forward." The directional arrow you already have is conceptually correct — just the color needs to be bolder.

→ Change color only, keep arrow

Finish marker

Keep your amber/gold (#f59e0b) but swap the flag for a 5-point star. Stars signal achievement and reward — more satisfying than a flag, and the finish is already the right color.

Hints & solution

Shift from green (#22c55e) to violet (#8b5cf6). This is the most impactful change — it removes the green conflict with teal start and makes hints feel like "magical help" rather than a second path.

→ Green → violet is the key move

Traversal path

Blue (#3b82f6) stays. It's the player's trail, and blue is neutral enough that it doesn't compete with teal start or amber finish. No change needed here.

→ Keep as-is
